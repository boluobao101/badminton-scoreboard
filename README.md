# 羽毛球计分板 · Badminton Scoreboard

一个**单文件、零依赖**的羽毛球电子计分板。手机横屏放在场边就能用，iPhone / iPad 与 Android 手机、平板通用，电脑浏览器同样可用。

- 全部代码在一个 `index.html` 里，双击即用，不需要安装、不需要联网、不需要后端。
- 比分占满半个屏幕，场边几米外也能看清；内置四套配色，室内馆、夜场、强光下都能选到合适的一套。

## 特性

- **BWF 21 分制**：每局 21 分，20 平后需净胜 2 分，30 分封顶。
- 可切换 **15 / 11 / 7 分制**，局数支持 **1 局 / 3 局 2 胜 / 5 局 3 胜**。
- **发球方与发球区提示**：按发球方当前比分的奇偶自动判定右区 / 左区，双打也能对。
- **局点 / 赛点提示**：谁再得 1 分就能拿下这一局、这一场，名字下方直接标出来。
- **自动换边**：每局结束交换左右显示；决胜局一方先到 11 分时再交换一次。
- **技术暂停提示**：每局到一半分数（21 分制即 11 分）时提醒。
- **局间 60 秒倒计时**：每局结束后自动开始，休息时间一眼可见。
- 点哪边给哪边加分；单点减分、整场撤销（可连续撤销）。
- **锁定计分**，防止擦汗、递水时误触。
- **历史战绩**：每场结束自动存档（局分、各局比分、用时），最多保留最近 30 场。
- 比分、局分、用时同屏显示；局分明细随时查看。
- 比赛结束可一键复制比分文本，方便发群。
- **本地自动存档**，误刷新、误关页面都不丢分。
- **全屏入口**，隐藏浏览器地址栏；手机也可「添加到主屏幕」当 App 用。
- 屏幕常亮（Wake Lock）、得分音效、语音报分，均可开关。
- 单文件、原生 JS、无框架、无外部请求，离线可用。

## 快速开始

### iPhone / iPad

1. 用 Safari 打开线上地址（把 `index.html` 部署到 GitHub Pages 或任意静态托管即可）。
2. 点「分享」→「添加到主屏幕」，之后从主屏幕打开就是全屏应用，没有地址栏。
3. 横屏使用效果最佳。

### Android

1. 用 Chrome 打开线上地址，横屏即可。
2. 或把 `index.html` 拷到手机，用文件管理器选择「用 Chrome 打开」。
3. Chrome 菜单 →「添加到主屏幕」，可以像 App 一样启动。

### 电脑 / 平板

直接双击 `index.html`，或用任意静态服务器打开。

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 加分 | 点击该方半屏区域（任意位置） |
| 减分 | 点击该方右下角「−」 |
| 撤销 | 顶栏撤销按钮，可一路回退到开局 |
| 锁定 | 顶栏锁图标，解锁前计分不响应点击 |
| 改名字 | 点击队名，或进设置修改 |
| 设置 | 顶栏设置图标：主题、赛制、分数、局数、音效、常亮等 |
| 局分明细 | 点击顶栏「局分」胶囊 |
| 历史战绩 | 设置 → 辅助 →「查看」 |
| 换左右显示 | 设置 → 辅助 →「交换」 |
| 全屏 | 设置 → 辅助 →「全屏」 |

键盘快捷键（桌面端）：`A` / `1` 给 A 方加分，`B` / `2` 给 B 方加分，`U` 撤销，`L` 锁定，`S` 设置，`Esc` 关闭弹层。

## 计分规则说明

- 采用**每球得分制**：每一回合的胜方得 1 分，同时获得下一回合发球权。
- 一局先到 21 分且领先 2 分者胜；20 平后继续，先到 30 分者胜（29 平时先到 30 即胜）。
- 发球区：发球方比分为偶数时在右发球区发球，奇数时在左发球区发球，界面右上角会显示当前发球区。
- 换边：每局结束后双方交换场地；进入决胜局后，一方先到 11 分时再交换一次。
- 局间与决胜局 11 分时有 60 秒技术暂停，界面会给出提示。

非标准赛制（15 / 11 / 7 分制、无封顶、不要求净胜 2 分）都可以在设置里调整，适用于训练赛、趣味赛。

## 兼容性

- iOS 16+ Safari、Android Chrome 105+ 支持完整的容器查询布局，比分会按面板尺寸自动缩放。
- 更老的浏览器会自动回退到 `vmin` 字号方案，功能不受影响。
- 屏幕常亮依赖 Wake Lock API：iOS 16.4+、Chrome for Android 支持；不支持的设备该开关无效，其余功能正常。
- 语音报分依赖 Web Speech API，部分机型语音包缺失时可能不发声。

## 部署到 GitHub Pages

本仓库用 GitHub Pages 的「分支部署」直接发布静态文件：

- **Settings → Pages → Build and deployment → Source** 选择 **Deploy from a branch**
- 分支 `main`、目录 `/ (root)`
- 推送到 `main` 后一两分钟自动重新构建

在线地址：<https://boluobao101.github.io/badminton-scoreboard/>

想在自己的仓库里部署，把 `index.html` 放进仓库根目录，按上面的路径设置一次即可，不需要 Actions workflow。

## 技术说明

- 单个 HTML 文件：CSS、JS、图标（内联 SVG / data URI）全部内联，无构建步骤。
- 比分字号用 CSS 容器查询（`cqh` / `cqw`）按每个半屏面板的尺寸计算，横屏、竖屏、平板都不会溢出。
- 主题由 `:root[data-theme]` 上的一组 CSS 变量驱动，切换只改属性，不重绘 DOM。
- 计分逻辑为纯函数式状态机：每次加分、减分、撤销都会写入 `localStorage`，刷新后按存档恢复。
- 撤销采用状态快照栈（最多 80 步），跨局也能回退。
